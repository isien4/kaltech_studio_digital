# Kaltech Studio Digital — mise à jour du 8 octobre 2026

## Publication sur GitHub Pages

Cette version est préparée et vérifiée localement. Elle ne remplace pas encore le site public.

1. Faites une sauvegarde du dépôt actuel.
2. Décompressez le ZIP puis ouvrez le dossier `kaltech_studio_digital-main`.
3. Remplacez les fichiers du même nom à la racine du dépôt GitHub. Transférez notamment `index.html`, `style.css`, `script.js`, `assets`, `robots.txt` et `sitemap.xml`.
4. Gardez `CNAME` contenant `kaltechstudiodigital.com`. Ne modifiez pas les réglages DNS et GitHub Pages déjà validés.
5. Ne placez pas le dossier complet dans un sous-dossier du dépôt : `index.html` doit rester à la racine.
6. Après le déploiement GitHub Pages, ouvrez https://kaltechstudiodigital.com/ et vérifiez les images et boutons.

## Vérifier le partage WhatsApp

Après publication, ouvrez directement https://kaltechstudiodigital.com/assets/partage-kaltech-v1.png pour vérifier que l’image est accessible.

Collez ensuite https://kaltechstudiodigital.com/ dans une nouvelle conversation WhatsApp et attendez l’aperçu avant d’envoyer. L’apparition de l’aperçu dépend du cache et du client WhatsApp ; elle n’a pas été testée en direct pendant la préparation. Si un ancien aperçu reste affiché, essayez https://kaltechstudiodigital.com/?partage=20261008 dans un nouveau message.

La redirection e-mail validée permet de recevoir les messages dans Gmail. Le lien `mailto:` ouvre l’application de messagerie du visiteur. Les réponses envoyées normalement depuis Gmail restent signées par l’adresse Gmail.
