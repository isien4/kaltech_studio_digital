# Refonte Kaltech Studio Digital

Version préparée le 2 octobre 2026. Les fichiers sont prêts pour GitHub Pages ; ils ne sont pas encore publiés.

## Aperçu

Ouvrez index.html dans un navigateur. Les images, styles et interactions sont locaux : aucun outil supplémentaire n’est nécessaire.

## Mettre à jour le dépôt

Après validation de l’aperçu, remplacez index.html, ajoutez style.css, script.js et le dossier assets à la racine du dépôt. Conservez le fichier existant Kaltech Studio Digital.png. Le dossier assets doit être transféré avec tous ses fichiers ; il ne suffit pas de remplacer index.html.

Conservez les réglages GitHub Pages actuels. Vérifiez ensuite la page publique, les images et le menu mobile, ainsi que les boutons WhatsApp, téléphone, e-mail et réseaux.

## Contenu

Les trois pôles, coordonnées, horaires, modalités standards de paiement et réseaux correspondent aux informations définies avec Kaltech. Les tarifs sont établis sur devis. Les anciens partenaires fictifs et les titres de portfolio non confirmés ne figurent pas dans cette version. Une galerie pourra être ajoutée avec des réalisations identifiées et autorisées à être présentées.

Le contact utilise WhatsApp, téléphone ou l’application de messagerie du visiteur. Aucun formulaire ne prétend envoyer un message. Le clic WhatsApp ouvre une conversation préremplie ; le visiteur doit lui-même envoyer son message.

## Vérifications effectuées

Affichage à 1440, 390 et 320 pixels de largeur ; absence de débordement horizontal, images et ancres locales présentes, menu mobile ouvrant et se refermant, aucune erreur JavaScript. Les destinations des réseaux ont été reprises des liens fournis ; leur accès externe n’a pas été testé automatiquement.
